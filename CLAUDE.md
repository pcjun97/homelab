# CLAUDE.md

GitOps config for a single-node k3s homelab on the host `november` (Debian 13), reachable only over Tailscale
(tailnet `tailbc93b.ts.net`).

- `kustomize/<app>/`: one Argo CD application per directory, generated by the ApplicationSet in `kustomize/homelab/appset.yaml`.
  Helm charts are rendered through kustomize's `helmCharts`.
- `ansible/site.yaml`: host setup (k3s, helm), run with sudo. `ansible/bootstrap.yaml`: cluster bootstrap (Tailscale secret,
  Argo CD, ApplicationSet, first syncs), run as the user.
- `docs/rebuild-2026-10.md`: decisions, lessons and the to-do list for the rebuild. Read it before proposing changes and keep it
  up to date as items are done.

## Workflow

- Don't apply, sync or run anything against the host or cluster until the change is in an open PR and the user has reviewed it.
  Read-only commands (`kubectl get`, logs, `--dry-run=server`) are fine.
- Keep PRs small and base them on `main`. The repo squash-merges, so only stack a PR on another when it depends on it, and rebase
  it onto `main` once the lower PR merges.
- Commit messages and PR titles use conventional prefixes (`feat:`, `fix:`, `chore:`, `refactor:`).
- Ask design questions as multiple-choice options with a recommendation.

## Conventions

- Pin chart versions, image tags and tool versions; Renovate bumps them (`renovate.json`): patch/minor auto-merge after CI,
  majors wait for Dependency Dashboard approval. A version Renovate can't detect needs a `customManagers` entry or a
  `# renovate:` comment.
- Ingress uses the Tailscale operator (`ingressClassName: tailscale`), giving `https://<name>.tailbc93b.ts.net`.
  Custom names (`https://<app>.chijun.website`, still tailnet-only) go through Traefik's Gateway API `traefik/traefik-gateway`
  with an `HTTPRoute` per app; ExternalDNS publishes the records. See the Domain decision in the rebuild doc. There is no nginx. The operator uses its default tags, `tag:k8s-operator` and `tag:k8s`.
- Storage: `local-fast` (default, `/mnt/fast`, SSD) for app config and `local-bulk` (`/mnt/bulk`, HDD) for large data, both from a
  self-run local-path-provisioner with `Retain` and `<namespace>/<pvc>/` folders. Media is not a PVC: apps mount `/mnt/bulk/media`
  as a `hostPath` volume (`type: Directory`), created by the `media` Ansible role, and pin themselves to `november` with a
  `kubernetes.io/hostname` nodeSelector. Avoid write-heavy workloads on the SSD.
- Apps mounting media run as UID/GID 1000. Apps with a config database use the `Recreate` strategy.
- There are no secrets in git. Secret values come from `~/.config/homelab/secrets.yaml` via the `secrets` Ansible role
  (`secrets_values.<key>`); add a new key to its `secrets_prompts` and to the playbook's `secrets_required`.
- Argo sync is manual on purpose: don't add automated sync, prune or selfHeal. Syncs use server-side apply, and apps compare with server-side diff.
- Ansible: system packages from apt, CLI tools from Homebrew (as the user). Role variables are prefixed with the role name;
  content lives in role `templates/` and `files/`, not inline in tasks.

## Checks before opening a PR

CI (`.github/workflows/ci.yaml`) runs these on every PR; run them locally first:

- `kustomize build --enable-helm kustomize/<app>` for every changed app
- `ansible-playbook --syntax-check` and `ansible-lint` for Ansible changes
